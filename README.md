A tiny Python program that writes one six-word story to `entry.txt` — an entry for the [Six Words, One Story bounty](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410).

> She wrote his eulogy. He proofread.

## Run

```sh
python3 main.py
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes `entry.txt` there.
